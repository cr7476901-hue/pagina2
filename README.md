# Lorenzo Mora — tienda online

Rediseño visual editorial de la tienda Lorenzo Mora, conservando el catálogo, las fotografías, las variantes, el carrito, la información institucional, reputación y contacto de la versión original.

## Desarrollo

Requiere Node.js 20.19+ o 22.12+.

```bash
npm install
npm run dev
```

Abrir http://localhost:3000

## Producción

```bash
npm run build
npm run preview
```

El sitio está construido con React, TypeScript, Vite y Tailwind CSS. Las imágenes originales están en `public/assets/lorenzo/`.
